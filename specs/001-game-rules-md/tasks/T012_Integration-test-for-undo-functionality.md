# T012. Integration test for undo functionality

## 描述

建立復原功能的整合測試，確保玩家能夠撤銷其遊戲動作並將遊戲狀態回復到之前的狀態。此測試需要驗證移動記錄的存儲、復原操作的執行，以及遊戲狀態的正確還原，同時遵循憲法原則 II (TDD)，此測試必須在實現之前寫好並且必須失敗。

## 工項 tasks

- [ ] 建立 `tests/integration/` 目錄結構（如果不存在）
- [ ] 建立 `test_undo.test.ts` 測試檔案
- [ ] 實現基本的復原功能測試場景：
  - [ ] 測試單次移動後的復原操作
  - [ ] 測試多次移動後的復原操作
  - [ ] 測試連續復原操作
  - [ ] 測試復原操作的限制（無動作可復原時）
- [ ] 實現複雜的復原功能測試場景：
  - [ ] 測試從 Tableau 到 Foundation 的移動復原
  - [ ] 測試從 Stock 到 Tableau 的移動復原
  - [ ] 測試翻牌動作的復原
  - [ ] 測試遊戲狀態包括分數的正確復原
- [ ] 實現移動歷史記錄的測試：
  - [ ] 驗證移動記錄的正確存儲
  - [ ] 驗證復原後歷史記錄的更新
  - [ ] 測試移動歷史的容量限制
- [ ] 實現用戶介面相關的復原測試：
  - [ ] 測試復原按鈕的啟用/禁用狀態
  - [ ] 測試復原操作的視覺反饋
  - [ ] 測試鍵盤快捷鍵 (Ctrl+Z) 的復原功能

## 測試方式

### 測試流程

AI 需要驗證以下項目來確認任務成功：

1. 測試檔案 `tests/integration/test_undo.test.ts` 已創建
2. 測試檔案包含所有必要的測試場景（單次復原、多次復原、復原限制等）
3. 測試使用適當的測試框架語法（Jest + React Testing Library）
4. 測試符合 TDD 原則，在相關實現不存在時應該失敗
5. 測試覆蓋了復原功能的所有核心邏輯
6. 測試包含適當的斷言來驗證遊戲狀態復原
7. 測試符合 TypeScript 嚴格模式要求

### 執行測試語法指令

```bash
npm test -- tests/integration/test_undo.test.ts
```

## AI 使用工具

執行此任務時需要使用的工具：

- **Read**: 讀取現有的測試檔案模板和專案結構
- **Write**: 創建測試檔案
- **Glob**: 搜尋現有的測試檔案模式
- **Bash**: 執行測試命令來驗證測試檔案創建成功
- **Edit**: 如需修改現有檔案結構

注意：此任務不需要 MCP 工具如 Test 或 Playwright，因為使用標準的 Jest 和 React Testing Library 進行測試。
