# T011. Integration test for game victory flow

## 描述

建立遊戲勝利流程的整合測試，驗證當玩家成功將所有卡片移至基礎牌堆(Foundation Piles)時，遊戲能正確識別勝利狀態並觸發相應的勝利處理流程。此測試需要模擬完整的遊戲勝利場景，包括卡片排列、移動驗證、勝利檢測以及勝利後的狀態處理。

根據 Constitution.md 的 TDD 原則，此測試必須在實際實作遊戲引擎前撰寫，並且必須失敗以確保測試的有效性。測試將驗證遊戲勝利的核心邏輯是否符合經典接龍遊戲規則。

## 工項 tasks

- [ ] 建立 `tests/integration/` 目錄結構（如果不存在）
- [ ] 建立 `test_victory.test.ts` 測試檔案
- [ ] 實作遊戲勝利場景的測試設定函數
- [ ] 撰寫測試案例：檢測所有四個花色基礎牌堆完成時的勝利狀態
- [ ] 撰寫測試案例：驗證勝利檢測邏輯的正確性
- [ ] 撰寫測試案例：測試勝利時的遊戲狀態更新
- [ ] 撰寫測試案例：驗證勝利統計資料的記錄
- [ ] 撰寫測試案例：測試勝利事件的觸發和處理
- [ ] 確保測試遵循 TypeScript 嚴格模式
- [ ] 驗證測試會失敗（因為尚未實作遊戲引擎）

## 測試方式

### 測試流程

1. 執行測試指令確認測試檔案載入正確
2. 驗證所有測試案例都會失敗（符合 TDD 紅-綠-重構循環的「紅」階段）
3. 檢查測試覆蓋率包含遊戲勝利的所有關鍵路徑
4. 確認測試案例涵蓋邊界條件和異常情況
5. 驗證測試輸出清楚指示缺少的實作部分

### 執行測試語法指令

```bash
npm test tests/integration/test_victory.test.ts
```
