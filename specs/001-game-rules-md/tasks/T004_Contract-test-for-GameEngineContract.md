# T004. Contract test for GameEngineContract

## 描述

為 GameEngineContract 建立合約測試，確保遊戲引擎介面的所有方法都符合預期的輸入輸出規格。這是 TDD 開發流程的第一步，必須在實作之前建立失敗的測試，以驗證遊戲核心邏輯的介面設計正確性。

測試應涵蓋：

- 遊戲生命週期方法 (初始化、發牌、重置)
- 卡牌移動操作 (移動卡牌、撤銷移動、自動完成)
- 遊戲狀態查詢 (驗證移動、取得有效移動、勝利檢查)
- 庫存牌堆操作 (抽牌、循環)
- 遊戲統計功能

## 測試方式

### 測試流程

執行合約測試並確認所有測試都失敗（因為尚未實作），驗證測試正確檢查了：

1. 每個介面方法的存在性
2. 方法的輸入參數型別正確性
3. 方法的回傳值型別正確性
4. 預期的錯誤處理行為
5. 事件系統的回調函數觸發

### 執行測試語法指令

```bash
npm test tests/contract/test_game_engine.test.ts
```
